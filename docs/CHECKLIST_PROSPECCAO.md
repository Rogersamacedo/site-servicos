# 📅 Checklist de Prospecção Diária - Operação Web

Use esta lista diariamente para manter a consistência comercial e preencher seu funil de novos clientes.

## 🛠️ Rotina Diária (Meta: 3 abordagens por dia)
- [ ] **Mapeamento Local:** Localizar 3 comércios em Ribeirão Preto (via Google Maps ou Instagram) que ainda não possuem site ou usam páginas antigas.
- [ ] **Validação do Lead:** Verificar se o estabelecimento possui um botão ou número de WhatsApp ativo para contato.
- [ ] **Disparo de Demonstração:** Enviar o script de abordagem correto (`docs/SCRIPTS_PROSPECCAO.md`) contendo o link do seu portfólio gratuito.
