# 🎯 Diretrizes de Escopo - Desenvolvimento Web Rogério M.

Este documento define os limites técnicos, entregáveis e regras de modificação para os projetos de Landing Pages voltados a comércios locais.

## 1. Limites do Projeto Padrão (Baseline)
*   **Página Única (Landing Page):** Estrutura focada em conversão dividida em até 5 seções dinâmicas.
*   **Hospedagem Otimizada:** Publicação usando infraestrutura serverless estável e gratuita (GitHub Pages).
*   **Automação de WhatsApp:** Configuração de gatilhos de links diretos com mensagens pré-formatadas para identificação automática do lead.
*   **Captura de Contatos (CRM):** Módulo de simulação frontend para captação de dados básicos.

## 2. Processo Rigoroso de Alterações (UX/Design)
*   **Rodada 1 (Rascunho):** Feita após a apresentação da estrutura básica. O cliente valida textos e alinhamento de blocos.
*   **Rodada 2 (Refinamento):** Ajustes finais de paleta de cores, ícones e substituição de fotos oficiais.
*   **Trabalho Fora de Escopo:** Alterações após a segunda rodada ou modificações na arquitetura depois de aprovadas serão tarifadas na modalidade de **Hora de Desenvolvimento Extra** (R$ 60,00/hora).
